# Analisador de Landing Page com IA

Projeto de automação criado com n8n para analisar landing pages e gerar recomendações de otimização de conversão.

## Stack utilizada

- n8n
- OpenAI
- HTTP Request
- Form Trigger

## Como funciona

O usuário envia a URL da landing page

→ o sistema faz o scraping da página

→ a IA analisa todo o conteúdo

→ gera um roast da página

→ entrega recomendações práticas para aumentar conversão

## O que a IA analisa

- headline
- copy
- CTA
- estrutura da página
- elementos de conversão
- oportunidades de melhoria

## Resultado final

O usuário recebe:

- análise crítica da página
- recomendações de CRO
- melhorias práticas para aumentar vendas/conversão
